## Rizzo PII 2.2.0

**Scanned documents and photos.** The app now reads PDFs with no text layer and images of pages
(phone photos, screenshots, multi-page TIFF) with a **local OCR pipeline**, anonymizes them and gives
back a redacted PDF where the PII is gone **from the pixels**, not just covered. Plus a completely
redesigned interface.

Model: **rizzo-pii-0.3B v1.5.0**, unchanged. Everything still runs on your CPU, offline.

### Highlights

- **Local OCR, CPU only.** The official [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) models
  (PP-DocLayout for the layout, PP-OCRv6 for text, SLANet_plus for tables) exported to ONNX and run
  by ONNX Runtime: no Paddle, no PyTorch, nothing leaves the machine. Reads headers, footers, stamps
  and tables, keeps the reading order on multi-column pages and straightens crooked scans.
  - `auto` (default) runs OCR only on pages without a text layer; `force` reads every page (useful
    for broken text layers); `off` never runs it. Presets `fast` / `balanced` / `accurate`.
  - Around 1 s per page on a laptop CPU with `balanced`.
- **Redaction on the pixels.** On scanned pages every PII is located character by character, the
  pixels underneath are overwritten, the original image is removed from the file and the page goes
  back with the placeholders written on top as real text. **Stamps** are covered too (they often
  carry names and registration numbers; can be turned off).
- **New interface.** Drag and drop anywhere on the card or paste a screenshot; the original document
  rendered page by page on the left with an OCR progress bar and an optional overlay of the
  recognized lines; on the right the anonymized text and the **redacted PDF** preview, downloaded
  from the same copy. Zoom, light/dark theme, and a settings panel with tags, OCR and server.
- **One OCR per document.** Results are cached in memory by file hash: preview, analysis and PDF
  export of the same file pay for the OCR once. A document already loaded is reused by id, no
  second upload.
- **API.** New `POST /ocr` (JSON page by page, optional lines with per-character boxes, NDJSON
  progress stream); `/analyze`, `/pdf`, `/pdf/preview` accept images and scanned PDFs; OCR options in
  `/settings`; OCR status in `/health`.
- **Lighter OpenCV in the packages.** The OCR needs only OpenCV's `core` + `imgproc`, so the
  installers ship a minimal build compiled in CI (no video, BLAS, OpenCL or codecs) instead of the
  full wheel. The OCR adds ~60 MB to the light installers.
