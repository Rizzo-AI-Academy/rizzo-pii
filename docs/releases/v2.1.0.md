## Rizzo PII 2.1.0

Same model, same results — a much lighter app. The engine now runs on **ONNX Runtime** instead
of PyTorch, and the default installer no longer carries the model: it downloads it from Hugging
Face the first time you open the app, once.

Model: **rizzo-pii-0.3B v1.5.0**, unchanged (fp32, no quantization).

### Highlights

- **Installer from 1.21 GB to ~90 MB** (Windows). On first launch the splash screen downloads the
  model (1.18 GB) with a real progress bar — MB, percentage, speed, time left — then the app is
  offline as before. Only the model weights are downloaded: your documents never leave the computer.
  - Pinned to an exact Hugging Face commit, every file checked by size + **sha256** before use.
  - Resumable: close the app or lose the connection halfway and it picks up where it stopped.
  - If the download fails you get a short reason, **Retry** and **Open folder** (to copy the files
    in by hand).
- **Offline installers** for machines without internet or networks that block `huggingface.co`:
  `…-offline.exe`, `…-offline.AppImage`, `…-offline.deb` have the model inside and never touch the
  network.
- **No more PyTorch inside the app.** Inference runs on onnxruntime with the same fp32 weights,
  verified against PyTorch: 0 differing entities on 305 texts, max logit difference 3e-4.
  On the Windows build: startup 8–10 s → 3–4 s, first analysis 3.6 s → 0.09 s, RAM ~870 → ~600 MB.
  Throughput on long documents is unchanged.
- **The ONNX model is on Hugging Face** (`onnx/` in
  [rizzoaiacademy/rizzo-pii-0.3B](https://huggingface.co/rizzoaiacademy/rizzo-pii-0.3B)), usable
  with onnxruntime from any language.
- **Linux packages are built by CI** on every release (`.AppImage` and `.deb`, light and offline),
  with a smoke test that starts the backend and anonymizes a sentence before publishing.
